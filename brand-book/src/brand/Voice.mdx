# Voice

Trust through clarity. LinkNMS speaks like a competent, unhurried professional
who has read the fine print and refuses to oversell. Plain nouns over hype; the
confidence comes from precision and candour, not adjectives.

- Lead with what’s true, limitations included. If a feature doesn’t exist yet,
  say so in the same breath.
- Address every party as equals in the same sentence — never copy that reads as
  the owner’s tool against the builder, or vice-versa.
- When describing the change history, state the boundary every time: it reveals
  that a record was altered; it does not prevent alteration.

## Say / Avoid

| Say | Avoid |
| --- | --- |
| “One record every side trusts.” | “tamper-proof”, “unhackable”, “bulletproof” |
| “Tamper-evident, not tamper-proof.” | “blockchain-secured”, “trustless” |
| “Planned vs. actual · Owner side / Builder side.” | “revolutionary”, “seamless”, “military-grade” |
| “The build, on the record.” | copy that frames one party against the other |

## Tagline

**Trust built-in.** — a double reading: trust designed *in*, and built like a
house. Set two-tone: **Trust** in Ink, *built-in.* in a faded grey.
